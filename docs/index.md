## Course overview

**ENME480** is the first course in the [Robotics and Autonomous Systems Minor](https://robotics.umd.edu/minor). This couse will cover:

- **Kinematics** — rigid motions, forward/inverse kinematics   
- **Dynamics** — planning, control
- **ROS 2 & Python** — modern robotics tooling and best practices  
- **Studios & Labs** — translate math into code on **UR3e** industrial arms  
- **Computer Vision** — aruco tag detection + pick & place for the final project
