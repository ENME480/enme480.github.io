## **Lab Structure**

### **Lab Session Types**
Programming studios will be held at the start of each lab assignment and will occur in the Kim building. The purpose of these is to give students time to write, test and debug code. Robot lab sessions will be held in the IDEA Factory building and will give students the opportuinity to run code on the physical robots. A rough schedule is provided below, but make sure to check Piazza and your syllabus for a more up to date verison. The labs will be group based and will build on one another until the final project, which will involve all the skills learned during the prior labs.
